# Нова

Голосовой помощник для Android: понимает русскую речь, ведёт записи, планы и расходы, ставит
напоминания и отвечает голосом. Базовые команды работают **без интернета** — распознавание речи
и разбор фразы идут на телефоне. Для свободных вопросов («почему небо голубое», «как приготовить плов»)
есть локальная модель **на самом телефоне** и, по желанию, облачные провайдеры.

---

## Разделы приложения

Пять вкладок нижней навигации — это и есть карта продукта:

| Раздел | Что там |
|---|---|
| **Нова** | Главный экран: обращение по имени, сфера голосового ввода, подсказки-примеры (берутся из «Что умеет Нова» и меняются), поле ввода, история разговоров, карточки дня |
| **Записи** | Заметки, идеи, покупки, долги, здоровье, секретные заметки, поиск по смыслу |
| **Планы** | Задачи, напоминания, таймеры, будильники, дни рождения, отправка плана в календарь телефона |
| **Расходы** | Расходы и доходы, категории, статистика по месяцам |
| **Настройки** | Голос и речь, AI, безопасность и разрешения, аккаунт, резервная копия, оформление, «Что умеет Нова», «О приложении» |

## Возможности

### На телефоне, без интернета

- **Расходы и доходы** — «Расход 850 на продукты», «зарплата 80000», «сколько потратил на кафе в этом месяце», «на что больше всего трачу». Есть мост к стороннему финансовому приложению, если оно установлено.
- **Траты из уведомлений банков** — Нова видит банковский пуш «Покупка 850 ₽ · Пятёрочка» и предлагает записать трату: сумма, магазин и категория уже заполнены. Режимы в «Расходы»: выключено, спрашивать (по умолчанию), записывать сразу; запись можно отменить из уведомления. Разбор локальный, по тексту уведомления — в банк приложение не входит. Поддержано 29 банковских приложений (Сбер, Т-Банк, Альфа-Банк, ВТБ, Райффайзен, Газпромбанк, Озон Банк, Яндекс Банк и другие).
- **Задачи и списки покупок** — «нужно сходить в зал в понедельник», «купи молоко, яйца и хлеб», «отметь задачу выполненной», «что купить?».
- **Напоминания, таймеры, будильники** — разовые и повторяющиеся, по геометке («напомни, когда буду дома»), с досылом пропущенного. Таймеры Нова громкие и работают в беззвучном режиме. В настройках — выбор: свои будильники или системные.
- **Заметки, идеи, память** — «запиши заметку», «у меня идея…», «добавь к идее…», «запомни, что…», поиск по смыслу. **Секретные заметки** — только на телефоне, открываются по отпечатку/PIN, в облако и в AI не попадают.
- **Долги, накопления, дни рождения** — «Саша должен мне 500», «отложил 2000 на ремонт», «у Маши день рождения 12 октября».
- **Сценарии** — «когда я говорю „спокойной ночи“ — поставь будильник на 7 и включи не беспокоить», дальше достаточно сказать «спокойной ночи». Свой сценарий собирается в конструкторе: «Настройки → Сценарии → ＋ Свой сценарий» — фраза-триггер, галочки функций (приветствие, погода, новости, план на день, задачи, напоминания, привычки, дни рождения, идеи, заметки, траты, курс валют, «не беспокоить», музыка) и свои команды текстом. Любой готовый сценарий и сценарий, созданный голосом, открывается в том же конструкторе: галочки уже отмечены, лишнее снимается, фраза переименовывается — и напоминание по расписанию начинает звать сценарий по новому имени. Сценарий по расписанию («каждый день в 9 читай сводку») и утренняя/вечерняя сводка со итогами недели приходят целиком: Нова здоровается по имени из настройки «Как вас зовут», зачитывает всё вслух, а полный текст остаётся в истории общения — уведомление его не обрезает, и по нажатию открывается чат с этой сводкой.
- **Диктовка** — «надиктую заметку»: слушает с длинными паузами, «готово» — и текст сохранён.
- **Команды телефону** — звонки (Нова сама нажимает «вызов»), сообщения, открытие приложений, фонарик, громкость, яркость, музыка, камера, скриншот, маршрут (в Яндекс Картах, Google Картах или 2ГИС — по фразе «в 2ГИС» или по выбору в «Сценариях», иначе в приложении, назначенном системой; место ищется в городе из настройки «Мой город», а название приводится к словарной форме — «до вокзала» → «вокзал, Новосибирск»), календарь, «не беспокоить». Через службу спецвозможностей — «назад», «домой», «недавние», уведомления, блокировка экрана. Музыку Нова включает и в своём плеере (фрагмент трека), и в чужом — Яндекс Музыка, «Звук», Spotify, VK, YouTube Music: она открывает поиск нужного трека, нажимает первую строку результата (для этого нужны спецвозможности) и просит плеер играть — команда уходит прямо в его медиа-сессию через доступ к уведомлениям, а клавиша телефона остаётся запасным путём.
- **Сообщения** — «прочитай сообщения», «что написала мама», «ответь Маше: буду через 10 минут» (Telegram, WhatsApp, VK, SMS — через доступ к уведомлениям).
- **«Где я?»** — называет улицу и ближайший дом по геолокации и сразу предлагает помощь: «вызови скорую» — набирает 103 и подсказывает адрес для диспетчера, «позвони маме» / «напиши маме» — звонит близкому из контактов или отправляет ему сообщение с адресом и координатами. Скорая, полиция, пожарные и спасатели вызываются по любой фразе («вызови скорую», «позвони в полицию») — без поиска в контактах.
- **«Нова, где ты?»** — громкий сигнал и фонарик, чтобы найти телефон.
- **Быстрые ответы** — время и даты, «сколько дней до…», калькулятор и проценты, перевод единиц, монетка, кубик.
- **Игры и сказки** — города, загадки, викторина, «угадай слово», сказки.
- **Привычки и здоровье** — вода, лекарства, давление, вес, сон, тренировки с таймером.
- **Кухня** — рецепт, ингредиенты с количествами и порциями, добавление списка в покупки, пошаговое приготовление с продолжением с того же шага.
- **Дни рождения и праздники** — включая плавающие даты (Пасха, Масленица) и именины, импорт из контактов.

### Из открытых источников (нужен интернет)

- **Погода** — MET Norway, Open-Meteo, wttr.in как резерв: если один источник недоступен, берётся следующий.
- **Курсы валют и криптовалют**, **новости**, **справка из Википедии**, **радио** (встроенные станции + каталог radio-browser).

### С искусственным интеллектом (по желанию)

- **Офлайн-модель прямо на телефоне** (см. ниже).
- **«Облако Нова»** — разговор через сервер Нова после входа в аккаунт, без своего ключа.
- **Свои провайдеры** — OpenAI, Google Gemini, Anthropic, OpenRouter, DeepSeek, Mistral, Groq, xAI, собственный сервер. Можно подключить несколько и расставить приоритет; при ошибке или лимите запрос уходит следующему, а без сети команда выполняется на устройстве.
- Что даёт AI: свободный разговор, тексты и поздравления, перевод, пересказ экрана, мозговой штурм, поиск по смыслу, сказки на заказ.

### Голос

- **Распознавание**: системное (Google) с автоматическим переходом на **встроенную офлайн-модель Vosk** (`scripts/fetch-vosk-model.sh` кладёт её в APK), в крайнем случае — системное окно ввода.
- **Синтез**: системный TTS или встроенный **«Голос Нова»** (sherpa-onnx + Piper) с несколькими русскими голосами — одинаково звучит на любом телефоне, включая прошивки с китайскими синтезаторами.
- **Род по имени**: имя ассистента задаёт род — «Нова», «Кира», «Алиса» и любое женское имя дают женский род и только женские голоса, «Джарвис», «Максим» — мужской род и только мужские голоса; при смене имени голос переключается сам. Ответы написаны в женском роде и для мужского имени согласуются автоматически («Записала» → «Записал», «Готова» → «Готов»). Имя из настройки «Как вас зовут» задаёт род обращения к собеседнику; неоднозначные имена (Саша, Женя, Валя) род не угадывают — Нова не будет обращаться неправильно.
- **Обращение «Нова»** без нажатия (фоновое прослушивание), слово остановки «стоп/хватит/замолчи» с эхоподавлением, приглушение музыки во время ответа.
- Вызов: кнопка на главной, плитка в шторке, ярлык, кнопки громкости, роль ассистента Android.

### Офлайн-модель на телефоне

| Вариант | Размер | Комментарий |
|---|---|---|
| Лёгкая · Gemma 3 1B | ~0,8 ГБ | быстрая и точная на бытовых вопросах — выбор по умолчанию |
| Сбалансированная · Qwen 2.5 3B | ~2,1 ГБ | умнее, но отвечает вдвое дольше |
| Умная · Qwen3 4B Instruct 2507 | ~2,5 ГБ | лучшая в сложных вопросах, нужен телефон от 12 ГБ |

Выбор проверен замерами на телефоне 8 ГБ (6 потоков): Gemma 3 1B — ~11–13 токенов/с и верные объяснения, Qwen3 1.7B и Qwen2.5 1.5B путаются в фактах, DeepSeek-R1-Distill уходит в рассуждения на английском, Qwen3 4B — 1,7 ток/с (30–40 секунд на ответ). Поэтому крупные модели предлагаются только телефонам с 10–12 ГБ памяти.

- Скорость ответа: модель загружается в память заранее, разобранная часть промпта остаётся в KV-кэше (следующий вопрос досчитывает только себя — 15–20 токенов вместо 150), характер разбирается при прогреве, ответ ограничен двумя предложениями. На телефоне 8 ГБ первый кусок ответа приходит за ~0,4 с, первая произнесённая фраза — за ~1 секунду; самый первый вопрос после запуска — 3–4 секунды, пока модель грузится.
- Озвучка идёт по мере генерации: ответ режется на фразы на ходу ([SpeechChunker.kt](app/src/main/java/ai/nova/app/voice/SpeechChunker.kt)), поэтому Нова начинает говорить, не дожидаясь всего текста, и не рвёт слова.
- Файл подбирается по объёму памяти телефона, скачивается с докачкой и проверкой контрольной суммы; лимит — 3 ГБ.
- Вместо «сырых» репозиториев Hugging Face показываются понятные варианты с размером и рекомендацией; для нестандартных случаев есть поле «свой `.gguf`» с мини-инструкцией.
- Реализация: llama.cpp 0.5.0 (JNI, [app/src/main/cpp/nova_llm.cpp](app/src/main/cpp/nova_llm.cpp)), каталог и загрузка — [ModelCatalog.kt](app/src/main/java/ai/nova/app/llm/ModelCatalog.kt) и [OfflineLlm.kt](app/src/main/java/ai/nova/app/llm/OfflineLlm.kt).

## Данные и приватность

- Локальная база — SQLDelight; на Android она зашифрована **SQLCipher**, ключ хранится в Android Keystore ([DatabaseFactory.kt](app/src/main/java/ai/nova/app/data/DatabaseFactory.kt)).
- Синхронизация — **local-first** через Supabase, только для вошедших в аккаунт; приложение работает и без аккаунта.
- **Резервная копия** — файл `.novabk`, зашифрован AES-256 паролем пользователя (пароль не восстановить). Есть автокопия по расписанию.
- Вход в приложение — отпечаток/лицо/PIN; есть режим «скрывать экран» (без скриншотов и в «недавних»).
- Обновления ставятся только из GitHub Releases этого репозитория и только после проверки подписи, имени пакета и версии.

## Сборка

Нужны JDK 17+ и Android SDK (`ANDROID_HOME`). Сборка сама скачивает llama.cpp и sherpa-onnx в `app/libs/`
(эти файлы в репозиторий не попадают).

```bash
# Android, отладочная сборка
./gradlew :app:assembleDebug        # app/build/outputs/apk/debug/app-debug.apk

# Отладочная сборка «Нова превью» — ставится рядом с обычной и не трогает её данные
./gradlew :app:assembleDebug -Pnova.preview=true   # ai.nova.app.preview

# Android, релиз (подпись — см. docs/SIGNING.md; без ключа подписывается debug-ключом)
NOVA_VERSION_NAME=X.XX.X ./gradlew :app:assembleRelease

# Офлайн-модель русской речи внутрь APK (иначе распознавание будет только системным)
./scripts/fetch-vosk-model.sh

# Тесты ядра без Android SDK
./gradlew -Pnova.skipAndroid=true :core:test

# Клиент для Windows (MSI)
./gradlew -Pnova.skipAndroid=true :desktop:packageMsi
```

Полезные свойства Gradle: `-Pnova.skipAndroid=true` (не собирать Android), `-Pnova.skipDesktop=true`
(не собирать Windows), `-Pnova.emulator=true` (добавить `x86_64`, чтобы работало на эмуляторе).

## Ограничения

- Офлайн-модель работает только на 64-битных телефонах (`arm64-v8a`) и требует свободной памяти под файл модели.
- Распознавание речи без интернета — только русский язык; офлайн-ядро понимает русские фразы.
- Часть команд (позвонить, открыть приложение, прочитать сообщения) требует разрешений: они запрашиваются в момент команды.
- Без интернета недоступны погода, курсы, новости, радио и облачные AI.
- Windows-клиент повторяет основные сценарии, но не все функции телефона (звонки, спецвозможности, виджеты).
